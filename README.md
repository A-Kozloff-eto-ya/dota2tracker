# Dota2Tracker

Тёмное SPA на React 19 + Vite + TypeScript для расчёта **персонального рейтинга** игроков
Dota 2 по открытым данным и сборки **равносильных (сбалансированных) команд**.

## Возможности

- **Два источника данных** — STRATZ (основной) + OpenDota (дополнение и фолбэк): поиск
  идёт сразу по обоим API (OpenDota знает Dota-ники, STRATZ — ники Steam-профилей),
  результаты сливаются с бейджами источника.
- **Трекинг игроков** — поиск по нику (OpenDota `/search` + STRATZ GraphQL `search`),
  добавление по `account_id`, `SteamID64`, `SteamID3` или ссылке на профиль Steam.
- **Формула рейтинга** (шкала 0–10 000, настраивается):

  ```
  Rating = scaleMax · (wTier·Tier + wPerf·Perf + wAct·Activity) / Σw
  ```

  - `Tier` — публичная медаль (`rank_tier`), бонус лидерборда; для приватных профилей —
    оценка MMR от OpenDota.
  - `Perf` — KDA, GPM, XPM, урон в минуту и винрейт последних N матчей.
  - `Activity` — общий винрейт (с поправкой на объём выборки) и пул героев.
  - Веса и пороги редактируются на вкладке «Формула» с мгновенным пересчётом.
- **Балансировка команд** — деление пула на 2–4 команды с равными средними рейтингами:
  точный перебор для 2 команд (до 18 игроков), снейк-драфт + локальная оптимизация для
  остальных случаев; опциональный учёт позиций 1–5; drag-and-drop для ручной подстройки.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + прод-сборка
npm run lint
```

## Данные и приватность

- **STRATZ API — основной источник данных**: винрейт, матчи, герои, behavior score и
  свежий ранк через GraphQL `player(steamAccountId)` — работает даже для профилей,
  которые в OpenDota пусты. Нужен бесплатный JWT-ключ: войдите на
  [stratz.com](https://stratz.com) через Steam, ключ — на странице API. STRATZ
  поддерживает CORS — запросы идут напрямую из браузера.
- **OpenDota API — дополнение и фолбэк**: медаль/оценка MMR/лидерборд из профиля,
  поиск по Dota-никам, полный фолбэк, если STRATZ недоступен. Ключ не обязателен
  (~60 запросов/мин), свой ключ — в настройках.
- **Ссылки вида `steamcommunity.com/id/<vanity>`** работают без ключей: приложение
  резолвит их через публичный XML-профиль Steam (`steamcommunity.com/id/<vanity>?xml=1`)
  по dev-прокси Vite (`/steamcommunity`). Если в настройках задан Steam Web API ключ,
  используется официальный `ISteamUser/ResolveVanityURL` (запросы через прокси
  `/steamapi` → `api.steampowered.com`, т.к. у Steam нет CORS).
- Бэкенда нет: список игроков, ключи, конфиг формулы и кэш живут в `localStorage`.
- Точный MMR скрыт Valve, поэтому рейтинг — локальная формула над публичными метриками.
